Start your own model run with web search

Extract the whole companion ZIP and open PowerShell in LOCAL-AI-CAD-KIT-NEXT. You need FreeCAD 1.x with FreeCADCmd and its MCP connection, Node.js, uv with Python 3.12, the selected assistant and a reachable SearXNG instance. CAD-NEXT.md covers setup. Model weights are obtained separately. Register your compatible llama-server executable, GGUF and matching vision projector with register-model-next.ps1. We used Qwen3.8-27B for the clip and Inkling 2 Mini with its supported Unsloth runtime for the enclosure.

Replace the registration paths with your actual files. For a text-only model such as Flint, omit the projector and add -TextOnly. Search defaults to http://127.0.0.1:8080. Point -SearxngUrl at your own search service. Cline Core batch mode requires explicit -AutoApprove for file, shell and CAD tools. For Hermes, supply the official installation via -HermesPython and -HermesEntry.

.\setup-harness.ps1 -Harness opencode2
.\register-model-next.ps1 -Name qwen -Model '.\models\Qwen3.8-27B-UD-Q4_K_XL.gguf' -Projector '.\models\mmproj-Qwen3.8-27B-UD-Q4_K_XL-F16.gguf' -Server '.\llama\llama-server.exe' -Sampling qwen -ThinkingBudget 8192
.\start-cad-web.ps1 -Harness opencode2 -ProfileFile 'models\profile-next-qwen.json' -TaskFile 'tasks\cable-clip-6mm.txt' -WebMode search -DryRun

The final line checks the configuration. Run that same line without -DryRun to start the job. The new entry point selects -WebMode search even when the option is omitted. If search is unavailable during a real run, the existing launcher stops before starting FreeCAD or the model. A comparison without the search adapter requires explicit -WebMode off. Use -FreeCAD and -FreeCADCmd for nonstandard installation paths. On a managed EVO, use its configured service-pause and launch procedure.

The task asks the model to record each external dimension in web-sources.json with its value, units, part or revision, original URL, location and access date. An unsupported dimension is marked unverified. A brief specification and a measurement of the finished part are recorded separately. The package check ran all five assistant routes with -DryRun.
